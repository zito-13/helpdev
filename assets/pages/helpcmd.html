Git

Versionning
Initialiser un dépôt
git init

Crée un dépôt Git vide ou réinitialise un dépôt existant dans le dossier courant.

Cloner un dépôt
git clone URL_DU_REPO

Copie un dépôt existant avec son historique complet sur ta machine locale.

Vérifier l’état
git status

Affiche les fichiers modifiés, ajoutés à l'index, ou non suivis par Git.

Préparer tous les fichiers
git add .

Ajoute toutes les modifications actuelles à l'index pour le prochain commit.

Créer un commit
git commit -m "message"

Enregistre l'état actuel de l'index dans l'historique du dépôt de façon permanente.

Voir l'historique visuel
git log --oneline --graph

Affiche l'historique des commits de manière compacte avec un arbre des branches.

Lister les branches
git branch

Affiche les branches locales. La branche courante est marquée d'un astérisque.

Changer de branche
git switch nom-branche

Bascule ton répertoire de travail sur la branche spécifiée.

Créer & basculer
git switch -c nom-branche

Crée une nouvelle branche et bascule immédiatement dessus.

Fusionner une branche
git merge nom-branche

Intègre les modifications de la branche indiquée dans ta branche courante.

Récupérer & fusionner
git pull origin main

Récupère les nouveautés du dépôt distant et les fusionne dans ta branche locale.

Envoyer les modifications
git push -u origin main

Envoie tes commits locaux sur le serveur distant et configure le suivi.

Mettre de côté
git stash

Sauvegarde temporairement les modifications non validées pour nettoyer le répertoire.

Annuler tout (Danger)
git reset --hard HEAD

Supprime toutes les modifications non commitées et revient au dernier commit.

MySQL

Base de données
Se connecter en Root
mysql -u root -p

Ouvre le client MySQL en ligne de commande. Le mot de passe sera demandé.

Lister les bases
SHOW DATABASES;

Affiche toutes les bases de données disponibles sur le serveur.

Sélectionner une base
USE nom_base;

Définit la base de données active pour exécuter les prochaines requêtes.

Lister les tables
SHOW TABLES;

Affiche toutes les tables contenues dans la base de données sélectionnée.

Voir la structure d'une table
DESCRIBE users;

Affiche les colonnes, types de données et clés d'une table spécifique.

Récupérer toutes les données
SELECT * FROM users;

Sélectionne toutes les colonnes et toutes les lignes d'une table.

Filtrer avec WHERE
SELECT * FROM users WHERE id = 1;

Récupère uniquement la ou les lignes qui respectent la condition demandée.

Insérer une ligne
INSERT INTO users (nom) VALUES ('Bob');

Ajoute un nouvel enregistrement dans la table avec les valeurs spécifiées.

Mettre à jour une ligne
UPDATE users SET nom='Alice' WHERE id=1;

Modifie les données d'un enregistrement existant. Attention à ne pas oublier le WHERE !

Supprimer une ligne
DELETE FROM users WHERE id = 1;

Supprime un ou plusieurs enregistrements. Toujours vérifier avec SELECT avant.

Exporter la base (Backup)
mysqldump -u root -p base > bkp.sql

Génère un fichier .sql contenant la structure et les données pour la sauvegarde.

Importer un Backup
mysql -u root -p base < bkp.sql

Restaure les tables et données à partir d'un fichier .sql dans une base existante.

PHP & Composer

Backend
Vérifier la version PHP
php -v

Affiche la version de PHP installée et active en ligne de commande.

Lancer le serveur local PHP
php -S localhost:8000

Démarre un serveur de développement rapide dans le dossier courant.

Exécuter un script
php script.php

Interprète et exécute un fichier PHP directement depuis le terminal.

Vérifier la syntaxe
php -l fichier.php

Vérifie s'il y a des erreurs de syntaxe (parse error) sans exécuter le code.

Installer les dépendances
composer install

Lit le composer.lock et installe les versions exactes des packages du projet.

Mettre à jour les dépendances
composer update

Met à jour les bibliothèques selon les règles définies dans composer.json.

Ajouter une librairie
composer require vendor/nom

Télécharge un nouveau package et l'ajoute automatiquement au composer.json.

Régénérer l'Autoload
composer dump-autoload

Met à jour le système de chargement automatique des classes après un renommage.

Terminal & Node

Outils CLI
Changer de dossier
cd nom-dossier

Permet de se déplacer dans l'arborescence vers un dossier enfant.

Remonter au parent
cd ..

Remonte d'un niveau dans l'arborescence des dossiers.

Lister le contenu
ls

Affiche les fichiers et dossiers (utiliser dir sous l'invite de commande Windows).

Créer un dossier
mkdir nom-dossier

Crée un nouveau répertoire vide à l'emplacement actuel.

Installer modules Node
npm install

Télécharge les dépendances JS du projet listées dans le package.json.

Lancer un script JS
npm run dev

Exécute un script personnalisé (ex: dev, build) défini dans le package.json.
